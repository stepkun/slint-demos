# Slint Demos

A set of UI demonstrators build with slint

**[Live web demo](https://stepkun.github.io/slint-demos/)**: the
[basic panel](https://stepkun.github.io/slint-demos/basic-panel.html) with the six flight
instruments and the [combined display](https://stepkun.github.io/slint-demos/combined.html) of
attitude, vertical speed, altitude, heading and airspeed, animated with demo values, running in
the browser as WebAssembly (built from [`web/`](web/)).
